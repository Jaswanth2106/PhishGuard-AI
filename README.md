# PhishGuard AI

"Understand Every Email Before You Trust It."

PhishGuard AI is an AI-assisted Email Threat Intelligence Platform that analyzes emails, URLs, screenshots, headers, and attachments to explain risks and educate users.

## Architecture
- **Frontend**: Next.js App Router, React, Tailwind CSS, TypeScript
- **Backend**: FastAPI, Python
- **Database**: Supabase (PostgreSQL, Auth, Storage)
